Making interference visible

DataForge 2026 Pathway blog · Team think loop (solo)

The sentence we are teaching

A fixed-shape synaptic state can absorb a stream of any length without a new memory slot per token — until a similar cue retrieves the wrong fact.

That sentence is falsifiable. If raising key similarity never hurts the synaptic probe, the demo is wrong. If lowering similarity never recovers the truth, the demo is also wrong. The lab makes either failure visible in under a minute.

Why this topic

The Pathway brief rewards one claim, a behaving substrate, and a real BDH module. Synaptic plasticity as short-term memory is on the approved list and is native to BDH: attention as synaptic memory, Hebbian writes during inference, associations in wiring rather than only in a growing cache.

What you do in the artifact

The page opens already writing A→RED, then C→GREEN, B→BLUE, C→GREEN, B→BLUE, C→GREEN.

  • Left: Transformer-style KV slots. Memory grows.
  • Right: Fixed 8×8 matrix with W ← (1−γ)W + η(k⊗v).
  • Probe: truth beside estimate, plus mixture shares. Move key similarity. Watch the answer change.

At the default similarity of 0.72 the synaptic side answers BLUE to cue A, whose true value is RED, while KV still answers RED. Drag similarity below about 0.39 and the synaptic answer flips back. That flip is the lesson.

The first build did not earn that sentence: it wrote A→RED twice, including last, so the self-match always outvoted the interfering write and confidence merely fell from 1.00 to 0.81. Lower confidence is not a wrong association. The stream was rebuilt so A is written once and early while the overlapping key repeats later.

BDH, without mythology

We cite Kosowski et al. (arXiv:2509.26507) for synaptic working memory. We cite BDH-CQ (arXiv:2608.09888) so CQ is not flattened into the same slider. We label our matrix a toy. We refuse to call BDH a Mamba SSM. We refuse to present blog figures as live official inference.

What we are not claiming

  • We did not reproduce Sudoku Extreme or ARC numbers.
  • We did not run official BDH weights.
  • Soft attention can interfere too; KV uses sharp nearest-key retrieval to isolate allocation.

One-minute critique

  1. Replay at similarity ≈ 0.72, probe A — synaptic should answer BLUE while KV answers RED.
  2. Similarity ≈ 0.1 — synaptic should recover RED.
  3. Ask where the crossover sits. It is s* = u⁴/(u²+1) with u = 1−γ, and η does not appear — η scales both traces equally. If we could not derive that, we would not own the code.
