What just happened

The left panel stores one explicit (key, value) slot per fact. Memory length grows with the stream. The right panel keeps a fixed d×d association matrix and updates it with a Hebbian write:

W ← (1 − γ) W + η · (k ⊗ v)

Reading with cue q returns W q. The preset writes A→RED once, early, then writes the overlapping key B→BLUE twice, later. Probing A sums every write weighted by how much its key overlaps A: RED arrives once and has decayed, BLUE arrives twice at strength s each. Past a similarity of roughly 0.39 the BLUE mass wins outright, so the fixed state answers BLUE to a cue whose true value is RED. The KV panel still answers RED, because it kept A its own slot.

That is the whole lesson: the synaptic side never allocated a slot per token, and the price is a retrieval that is confidently wrong rather than merely uncertain.

Honesty label. This is an independent teaching toy. It is not an official BDH or BDH-CQ checkpoint, and it is not a Mamba-style state-space model. It isolates one mechanism — synaptic / fast-weight memory — so you can falsify the claim above by moving the similarity slider.

Where this shows up in BDH

In Dragon Hatchling (BDH), working memory during inference is not a growing token cache alone. The paper describes synaptic plasticity with Hebbian learning: co-active neurons strengthen a connection, so recent associations live in the wiring itself for a short horizon (Kosowski et al., arXiv:2509.26507). That is the design pressure this explainer isolates: where does the association live, and what fails when capacity is fixed?

BDH

Attention reformulated as synaptic memory that updates as the model reads. Reported sparse non-negative activations and monosemantic synapses at the concept level. GPU-friendly formulations exist; the public toy code is educational, not the full production stack.

BDH-CQ

Same family, different adaptation story: learning from demonstrations and reasoning without a written chain of thought, with adaptation in recurrent state rather than evaluation-time parameter updates arXiv:2608.09888. CQ’s recurrent-state adaptation faces related capacity trade-offs, but its demonstration→latent-reasoning path is distinct from Hebbian outer-product writes — the fixed-state failure mode here is illustrative, not identical. Do not collapse BDH-CQ into “just Hebbian writes.”

Deeper walkthroughs from Pathway: From Attention to Synapses, Why BDH Uses a Brain-Inspired Architecture, The Equations of Reasoning, and the official toy implementation github.com/pathwaycom/bdh.

Limitations you should keep

  • A single overlapping write does not flip the answer. Because a cue matches its own key at 1.0 and an overlapping key at only s < 1, one competing write can lower confidence but cannot win. This preset writes the overlapping key twice so accumulated mass can beat the decayed original. Interference needs repetition or decay, not just similarity — the earlier version of this page overstated that, and the stream was rebuilt to match.
  • Low-dimensional keys exaggerate interference; real models use higher capacity and learned geometries.
  • The toy ignores sparsity, inhibition, and scale-free connectivity that BDH emphasizes.
  • Soft attention in a KV cache can also bleed; the left panel uses sharp nearest-key retrieval to show the allocation difference cleanly.
  • Published BDH results and this simulation are different evidence levels — do not treat one as the other.

Sixty-second test

  1. Leave similarity at 0.72. Read the green/red theory banner first — it should already predict WRONG — then confirm synaptic BLUE, KV RED.
  2. Drag similarity down through the live s* value. The banner and the synaptic label should flip together.
  3. Land on 0.10. Both sides read RED. Sweep η at 0.72: answer stays BLUE (η cancels).
  4. Raise γ and watch s* fall — decay makes the fixed state fail earlier. Then explain the claim in your own words.

The crossover is a property of this preset, not a universal constant. For this stream it is exactly s* = u4 / (u2 + 1) with u = 1 − γ: 0.500 at γ = 0, 0.388 at γ = 0.08, 0.203 at γ = 0.25. Raising decay makes the fixed state fail earlier, because the original trace fades faster than the repeated ones. Changing η moves nothing — it scales both traces equally, so the two sides cross at the same place. Try it: the answer at 0.72 stays BLUE at every η.
